Edge-AI Home Monitoring System

Most smart homes are leased, not owned. Every command you send travels to a cloud you don't control, owned by a company with interests misaligned to yours. This system proves that meaningful control of your physical space doesn't require surrendering it to a vendor. Edge-AI Home Monitoring is a locally-governed, vendor-independent home automation platform designed to answer: can a household be sovereign over its own infrastructure?

Py-Watchdog: Smart Folder Automation Hub

A smart open-source tool with Python which is running in background and organize automatic the Downloads and Desktop folder! The project delivers 3 major QoL improvements: Automatic Downloads organization — no more manual sorting. Desktop cleanup — keeps both Downloads and Desktop organized in the background. Custom smart rules — users can organize files by keywords, prefixes, and custom patterns instead of only file extensions.

Python Open Source Automation

Remote PC Control & Monitoring Server

The Remote PC Control & Monitoring Server is a web-based dashboard designed to monitor system performance and manage PC operations remotely. Built using Flask for the backend and Bootstrap for a modern, responsive UI, the project provides real-time visibility into CPU, RAM, disk, network, and battery status. It also includes functional controls for volume adjustment, system sleep, shutdown, and restart, alongside a live process tracker.
